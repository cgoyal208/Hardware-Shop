# Hardware-Shop

A responsive hardware storefront built with HTML, CSS and JavaScript. It includes product browsing, category filtering, search, price sorting, product details, a cart saved in local storage, and WhatsApp ordering.

## Run locally

Open `index.html` in a browser, or start a local server from this folder:

```powershell
python -m http.server 5173
```

Then visit `http://localhost:5173`.

## Before publishing

Replace the sample shop address, phone and WhatsApp number, email, map query, social links and sample customer reviews in `index.html` and `app.js`. The catalog is in `products.js`.

Product photos, Google Fonts, Lucide icons and the embedded map load from external services and require an internet connection.
